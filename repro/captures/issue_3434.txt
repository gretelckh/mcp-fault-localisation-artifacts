## 4. Why it happens

`Client(server)` goes through the in-process `DirectDispatcher`; when the client's progress_callback throws `RuntimeError: consumer failed`, the exception propagates back into server-side tool execution, and a tool that should have returned `done` instead fails with `UnexpectedToolError: Error executing tool work` (mcp/server/mcpserver/tools/base.py:210), with the real cause masked by generalization. The source is the caller's callback (Client side), but the reported layer is Server — a layer mismatch plus masking.
