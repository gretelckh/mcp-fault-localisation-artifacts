## 2. What the reporter described

refresh 端点只认 oauth_metadata.token_endpoint，否则退回 urljoin(origin, '/token')；重启后 metadata 尚未发现，于是 refresh POST 打到根路径 /token（应为 /auth/token），404 刷新失败并把裸 HTTP 404 泄漏给调用方

## 3. What we captured

Captured in our run (evidence tier B).

```
AS mounted under /auth; refresh POST hit '/token' (expected '/auth/token'); final status=404, no MCP-layer error raised
```

## 4. Why it happens

refresh 端点解析只认 `oauth_metadata.token_endpoint`，否则退回 `urljoin(origin, '/token')`；进程重启、metadata 尚未发现时，授权服务器挂在 `/auth` 路径下的 refresh 被打到根路径 `/token`，404 刷新失败并把裸 HTTP 404 直接泄漏给调用方，属 caller-exception（端点解析缺陷）。
