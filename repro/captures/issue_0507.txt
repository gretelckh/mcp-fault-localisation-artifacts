Trigger, as recorded during the study:

```text
sse_client('http://127.0.0.1:9210/sse') connects to an SSE endpoint that returns 404
```

## 2. What the reporter described

When connecting via SSE, the endpoint returns 404, mcp sse_client throws HTTPStatusError, and connection establishment fails

## 3. What we captured

Captured in our run (evidence tier A).

```
RAISED:HTTPStatusError:Client error '404 Not Found' for url 'http://127.0.0.1:9210/sse'
```

## 4. Why it happens

When the SSE client connection is established, the endpoint returns 404, and the client directly throws `HTTPStatusError` instead of converting it to an MCP error, exposing a bare exception to the caller — a Transport/HTTP defect.
