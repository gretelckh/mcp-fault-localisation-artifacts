## 1. What was run

Trigger, as recorded during the study:

```text
OAuthClientInformationFull(client_id='c', scope=None).validate_scope('read')
```

## 2. What the reporter described

validate_scope incorrectly rejects any request when the client has no registered scope (None): validate_scope(None, 'read') throws InvalidScopeError: Client was not registered with scope read.

## 3. What we captured

Captured in our run (evidence tier A).

```
validate_scope(scope=None, req='read') -> RAISED InvalidScopeError: Client was not registered with scope read
```

## 4. Why it happens

`validate_scope` incorrectly rejects any request when the client has no registered scope (None): `validate_scope(None, 'read')` throws `InvalidScopeError: Client was not registered with scope read`. When there are no required scopes, the request should be allowed; this logic defect causes legitimate requests to be rejected — a single-layer logic defect.
