## 1. What was run

Harness entry: `issue_3566.py::repro_3566`

Trigger, as recorded during the study:

```text
union_scopes('read','read,write') and validate_scope(scope='read,write', req='read')
```

## 2. What the reporter described

RFC 6749 separates scopes with spaces, but real authorization servers (such as Linear) return them comma-separated. union_scopes/validate_scope split by spaces, treating 'read,write' as a single scope, causing validation to fail

## 3. What we captured

Captured in our run (evidence tier A).

```
union_scopes('read','read,write') -> 'read read,write' (Expected 'read write'); validate_scope(scope='read,write', req='read') -> RAISED InvalidScopeError
```

## 4. Why it happens

RFC 6749 separates scopes with spaces, but real authorization servers (e.g. Linear) return them comma-separated. `union_scopes`/`validate_scope` split on spaces, treating `read,write` as a single scope, which causes validation failures/merge errors — a single-layer logic defect.
