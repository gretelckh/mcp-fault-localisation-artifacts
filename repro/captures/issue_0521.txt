Trigger, as recorded during the study:

```text
After 4 Clients connect, each Client exits in an independent asyncio task
```

## 2. What the reporter described

Multiple MCPClients perform entry/exit across tasks, the transport's cancel scope management across tasks fails, throwing CancelledError: Cancelled by cancel scope

## 3. What we captured

Captured in our run (evidence tier A).

```
RUN EXC: CancelledError: Cancelled by cancel scope
```

## 4. Why it happens

When multiple MCPClients perform cross-task entry/exit, the transport's cancel scope ownership gets confused and `CancelledError: Cancelled by cancel scope` is thrown. Exposed to the caller as a bare exception — a caller-exception.
