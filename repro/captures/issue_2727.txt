## 2. What the reporter described

The streamable_http client does not send the Origin header and is rejected (403) by a spec-compliant (cross-origin protection) server, and the client gets MCPError: Server returned an error response

## 3. What we captured

Captured in our run (evidence tier A).

```
enter RAISED:MCPError:Server returned an error response

```

## 4. Why it happens

The streamable-http client request does not set the `Origin` header (`_prepare_headers` only includes accept/content-type/session-id/protocol-version), and a spec-compliant cross-origin-protection server rejects it with 403, so the client gets `MCPError: Server returned an error response`. The source is Transport (missing HTTP header), exposed to the caller as a bare exception — a caller-exception.
