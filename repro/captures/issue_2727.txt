## 2. What the reporter described

streamable_http 客户端不发送 Origin 头，被符合规范的（跨域保护）服务器拒绝(403)，客户端得到 MCPError: Server returned an error response

## 3. What we captured

## 4. Why it happens

streamable-http 客户端请求未设置 `Origin` 头（`_prepare_headers` 只含 accept/content-type/session-id/protocol-version），符合规范的跨域保护服务器以 403 拒绝，客户端得到 `MCPError: Server returned an error response`。源是 Transport（HTTP 头缺失），以裸异常暴露在调用方，属 caller-exception。
