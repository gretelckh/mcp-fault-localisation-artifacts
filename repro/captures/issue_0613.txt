## 2. What the reporter described

When connecting via SSE, the endpoint returns 401 (authentication failed), mcp sse_client throws HTTPStatusError, and connection establishment fails

## 3. What we captured

Captured in our run (evidence tier A).

```
RAISED:HTTPStatusError:Client error '401 Unauthorized' for url 'http://127.0.0.1:9211/sse'
```

## 4. Why it happens

When the SSE client connection is being established, the endpoint returns 401 (authentication failure); the client directly throws `HTTPStatusError` instead of triggering authentication / converting to an MCP error, exposing a bare exception to the caller, a Transport/HTTP authentication defect.
